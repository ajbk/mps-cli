# Pilates Exercise Flashcards

Original teaching flashcards for MPS exercise planning. These cards are grouped
by apparatus or context:

1. Reformer
2. Mat
3. Stand / Standing
4. Chair

Printable generated deck:
[Exercise Flashcard Deck](exercise-flashcard-deck.html).

Category deck links:

- [Reformer](exercise-flashcard-deck.html#Reformer)
- [Mat](exercise-flashcard-deck.html#Mat)
- [Stand / Standing](exercise-flashcard-deck.html#Stand)
- [Chair](exercise-flashcard-deck.html#Chair)

They are written to be compatible with a Balanced Body-style movement lens:
whole-body movement, trunk integration, lower-body training, upper-body
training, mobility and restoration, breath, control, precision, flow, and
client-appropriate progressions. Do not treat this as copied Balanced Body
manual content. Use it as an original MPS teaching aid and adapt to the
instructor's training, client history, and studio safety rules.

Public reference points:

- Balanced Body Movement Principles:
  https://www.pilates.com/education/movement-principles-pilates-training/
- Balanced Body Pilates Instructor Training:
  https://www.pilates.com/education/pilates-instructor-training/

## Card Format

- **Front:** exercise name plus the teaching question.
- **Back:** level, movement objective, Balanced Body-style principle, cue,
  regression, and progression.
